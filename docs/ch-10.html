第 10 章：安全 (Security)

本章涵盖主题

  • 设备安全：设备加固技术
  • 二层安全：二层安全考量
  • 三层安全：控制平面安全
  • 网络覆盖和远程访问：VPN 和覆盖技术

基础内容 (Foundation Topics)

设备安全 (Device Security)

设备加固 (Device Hardening)

加固措施 说明
管理平面保护 限制管理访问（SSH、ACL、控制平面监管）
控制平面保护 限制控制平面流量（CoPP、CPPr）
数据平面保护 iACL、基础设施 ACL
不必要服务关闭 关闭未使用的端口和服务
密码加密 使用 type 6/8/9 而非 type 5/7
AAA 认证 集中认证、授权和审计
日志记录 集中日志和告警
NTP 同步 确保时间一致用于日志关联

管理平面安全

技术 说明
SSH v2 替代 Telnet，加密管理流量
ACL 限制管理访问来源
管理 VRF 将管理流量隔离到独立 VRF
带外管理 (OOB) 独立的管理网络
NetFlow 流量分析和异常检测

控制平面安全

技术 说明
CoPP (控制平面监管) 限制到控制平面的流量速率
CPPr (控制平面保护) 更细粒度的控制平面保护
rACL (接收 ACL) 限制发送到路由处理器流量
BGP TTL 安全 限制 BGP 邻居的 TTL
MD5 认证 路由协议认证

数据平面安全

技术 说明
iACL (基础设施 ACL) 限制到基础设施设备的流量
uRPF (单播反向路径转发) 防止 IP 欺骗
端口安全 限制接入端口的 MAC 地址
DHCP Snooping 防止 DHCP 欺骗
动态 ARP 检测 (DAI) 防止 ARP 欺骗
IP Source Guard 防止 IP 欺骗

二层安全 (Layer 2 Security)

二层攻击与防御

攻击 说明 防御方法
STP 攻击 流氓交换机成为根桥 Root Guard、BPDU Guard
VLAN 跳跃 通过标签注入访问其他 VLAN 关闭 DTP、VLAN ACL
MAC 欺骗/泛洪 MAC 地址泛洪攻击 CAM 表 端口安全、动态 ARP 检测
ARP 欺骗 中间人攻击 DAI、DHCP Snooping
DHCP 欺骗 流氓 DHCP 服务器 DHCP Snooping
CDP 攻击 利用 CDP 信息 关闭不必要的 CDP

二层安全最佳实践

实践 说明
关闭未使用的端口 防止物理接入
PortFast + BPDU Guard 接入端口快速转发 + 防止流氓交换机
VLAN ACL 限制 VLAN 间流量
Private VLAN 限制同一 VLAN 内设备间通信
802.1X 认证 基于端口的网络访问控制
MACsec 二层加密

三层安全 (Layer 3 Security)

控制平面安全

技术 说明
路由协议认证 OSPF、IS-IS、BGP、EIGRP MD5/SHA 认证
BGP TTL 安全 (GTSM) 限制 BGP 包的 TTL 值
前缀列表过滤 过滤路由更新
路由映射 (Route Map) 基于策略控制路由
最大前缀限制 防止路由表爆炸

数据平面安全

技术 说明
iACL 基础设施 ACL，保护网络设备
uRPF 防止 IP 欺骗
NetFlow 流量分析和异常检测
QoS 安全 防止 DoS 攻击影响关键流量

网络覆盖和远程访问 (Network Overlay and Remote Access)

VPN 类型

类型 特点 适用场景
站点到站点 IPsec VPN 固定站点间加密隧道 固定站点互连
远程访问 VPN 用户到网络的加密连接 远程办公
SSL VPN 基于 Web 的 VPN 零客户端远程访问
DMVPN 动态多点 VPN 大规模动态站点
FlexVPN 基于 IKEv2 的灵活 VPN 现代企业 VPN
GET VPN 组加密传输 VPN 大规模固定站点

IPsec VPN 组件

组件 说明
IKE (Internet Key Exchange) 密钥交换协议
SA (安全关联) 定义加密参数
ESP (封装安全载荷) 加密和认证
AH (认证头) 仅认证
隧道模式 vs 传输模式 隧道模式加密整个原始数据包

远程访问 VPN 设计考量

考量 说明
认证方式 双因素认证、证书
访问控制 基于角色的访问 (RBAC)
端点安全检查 主机检查（防病毒、补丁等）
分离隧道 仅企业流量走 VPN
全隧道 所有流量走 VPN
负载均衡 多 VPN 网关负载分担
