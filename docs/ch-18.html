基础内容 (Foundation Topics)

CCDE 考试概述

CCDE（Cisco 认证设计专家）是 Cisco 最高级别的设计认证。考试分为两个阶段：

阶段 名称 形式 时长
阶段 1 CCDE Written Exam (400-007) 选择题 2 小时
阶段 2 CCDE Practical Exam 场景设计题 8 小时

考试主题分布

主题 权重
Layer 2 Control Plane ~10%
Layer 3 Control Plane ~15%
Network Virtualization ~10%
Network Services and Management ~10%
Network Resiliency ~10%
Security ~10%
Transport Technologies ~5%
Network Design ~15%
Enterprise Architecture ~15%

考试准备策略

阶段 1：知识获取

步骤 内容
阅读全书 系统学习每一章的 Foundation Topics
完成每章测验 通过 "Do I Know This Already?" 评估理解
定义关键术语 掌握每章的 Key Terms
完成复习任务 每章的 Exam Preparation Tasks

阶段 2：知识巩固

步骤 内容
回顾 Key Topics 复习每章标记的关键主题
完成记忆表 填写 Appendix D 的 Memory Tables
对比设计选项 理解每种技术选项的优劣和适用场景
练习场景分析 思考业务驱动力如何影响设计决策

阶段 3：考前冲刺

步骤 内容
模拟考试 使用 Pearson Test Prep 软件
薄弱点强化 针对薄弱主题深入复习
场景练习 练习设计场景分析
时间管理 练习在时限内完成答题

CCDE 核心思维模式

💡 最重要的不是记住技术细节，而是理解设计思维

思维模式 说明
业务驱动 每个设计决策都由业务需求驱动
没有标准答案 每个场景有其独特需求、约束和优先级
避免过度设计 解决当前问题，不多不少
权衡取舍 在功能、成本、复杂度之间取得平衡
全局视角 考虑整个网络而非单一模块
简单性优先 在满足需求前提下选择最简单方案

考试答题策略

策略 说明
先读问题 理解被问的是什么
识别约束 找出场景中的约束条件
识别优先级 确定业务优先级
排除法 排除明显不合适的选项
时间管理 不要在单个题目上花太多时间
标记不确定题 先标记，最后回来检查
